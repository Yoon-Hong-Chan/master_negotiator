# 16. 결국 모든 협상은 둘로 나뉜다
- 이익 중심의 협상 vs 관계 중심의 협상
  - 관계와 이익은 반비례 -> 나의 이익을 추구하다 보면 관계가 나빠지기 마련
  - 상대와의 지속성으로 관계 또는 이익 중심의 협상인지 알수 있음
    - 상대를 앞으로도 계속 봐야 한다면, 관계 중심의 협상
- `뛰어난 협상가란 이익 중심으로 만난 사람을 관계 중심으로 바꿀 수 있는 사람`
- 관계 중심의 협상에선 에임 하이 하지 말라고 함
  - 터무니 없는 에임 하이는 상대와의 신뢰를 훼손할 수 있음
- 관계 중심의 협상에선 단기간의 경제적 이익보다 신뢰나 평판이라는 오래가는 가치가 훨씬더 중요

# 17. 협상 테이블에서 해선 안될 세 가지 행동
- 협상에서 하지 말아야할 것
  - 감정의 언어가 아닌 판단의 언어를 쓰는 것
    - '상대의 언론 플레이에 피가 거꾸로 솟음' vs '상대편은 겉과 속이 완전히 다른 사람' -> 후자가 더 안좋은 표현
    - 상대에 대해서 판단하지 말고, 내 감정을 표현하는게 나음 -> 상대를 낙인 찍는건 매우 불쾌한 경험
    - 감정을 쓰면 내가 원하는 메시지를 전달하면서도 상대와의 관계가 단절되는 걸 막을 수 있음
  - 협상 테이블에서 '귓속말'을 하는 것
    - 귓속말은 괜한 오해를 불러일으킴
    - 차라리 종이에 써서 소통하는게 나음
  - 협상 테이블에서 적극적 거짓말하는 하는 것
    - 적극적 거짓말: A인데 B라고 주장하는 것
    - 소극적 거짓말: A인데 A라고 정확히 밝히지 않는 것
    - 상대가 나에게 불리한 정보를 묻더라도 절대 적극적 거짓말을 하면 안됨 -> 말할 수 없는 입장이라면 침묵하는게 나음

```
소극적 거짓말에서 왜 축협 청문회에 정몽규 회장이 떠올랐는지....
```

# 18. 우리 딸이 갈소원보다 예쁜 이유
- 상대가 이성적으로 완벽해도, 뭔가 내 감정을 거슬리면 그 협상은 어려워짐
- 협상 테이블에서 상대가 나에 대해 좋은 감정을 갖게 하는 방법
  - 미러링 원리를 활용하는 것
    - 상대에게 내가 그와 비슷한 사람이라는 동질감을 심어줘 호감을 극대화 하는 방법
    - 나에 대한 소개를 상대의 입장에 맞게 소개
      - 정주영 회장이 소련에서 열심히 일해서 돈을 번 '부유한 노동자' 라고 소개
      - 미셸 오바마 여사가 중국에서 가장 '중국다운'색의 붉은 드레스를 입고 다닌 것
- 사람이 어떤 의사결정을 할 때는 사실도 물론 중요하지만, 감정이 궁국적으로 더 큰 영향을 미침
